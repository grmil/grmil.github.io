## Budget Manager

[View on Github](https://github.com/grmil/budget-manager)

This was a fun project I did over the summer. It's a CLI tool written in C++
that uses a database to manage expenses, budget categories, and spending
overviews. I personally use this on my home server and access it remotely using
a small API that I connect to on my phone. I have automation set up using a
Python script that reads in transactions and runs the CLI tool on a timer.

## DEVSH (In Progress)

I am currently making my own UNIX shell implementation in C. I am planning on

## Parallel Algs (In Progress)

[View on Github](https://github.com/grmil/parallel-algs-research)

I just started this project as an attempt to learn more about parallel
computing and MPI in general. The goal for this project is to develop some
simple foundational algorithms from linear algebra serially, then parallize
them.
